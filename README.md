# Dept Workload Manager — релизы

**Dept Workload Manager** — программа для распределения учебной нагрузки на
кафедре: нагрузка загружается из файла выгрузки учебного отдела,
преподаватели назначаются на дисциплины перетаскиванием, итоговые часы по
каждому преподавателю выгружаются в XLSX/ODS. Работает офлайн, все данные
хранятся локально, интерфейс на русском.

## Веб-версия

Без установки, прямо в браузере:
**https://sskroi.github.io/dept-workload-manager-releases**

Данные веб-версии хранятся в браузере, поэтому не очищайте данные сайта и
делайте резервные копии на странице «Настройки».

## Desktop-версия

Скачать сборку для Windows можно на странице
[Releases](https://github.com/sskroi/dept-workload-manager-releases/releases) —
используйте последний релиз.

## Зачем этот репозиторий

Здесь публикуются только готовые сборки программы и размещается веб-версия —
исходного кода тут нет. Программа сама проверяет обновления через этот
репозиторий (Настройки → Обновления).
